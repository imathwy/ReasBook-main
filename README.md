# ReasBook: Integer Programming

This branch contains a single ReasBook entry for:

Michele Conforti, Gerard Cornuejols, and Giacomo Zambelli, *Integer Programming*, Graduate Texts in Mathematics 271, Springer, 2014.

- Lean source: [`ReasBook/Books/IntegerProgramming_Conforti_2014/`](./ReasBook/Books/IntegerProgramming_Conforti_2014/)
- Entry point: `IntegerProgramming_Conforti_2014.Book`
- Contributor: TropicalFatFish

The snapshot is allowed to contain `sorry`; it is intended as the current best compile-oriented version for this book.

## Build

```bash
cd ReasBook
lake build ReasBook
```
